후면 충전방법

스탬프 후면의 잉크 주입구에 천천히 잉크를 넣는 방식입니다.
설명서에 표시된 고객님의 스탬프 타입을 선택해 주세요.

B타입C타입D타입

B TYPE / 후면주입

B 타입 후면주입 리필 방법

B 타입 후면주입 안내입니다.
설명서에 표시된 타입이 B인지 확인해 주세요.

  1. 후면 주입구를 확인합니다

    스탬프의 손잡이 부분을 열어 B 타입 주입구 위치를 확인해 주세요.

  2. 잉크를 천천히 넣습니다

    주입구에 잉크가 넘치지 않도록 소량씩 천천히 충전해 주세요.

  3. 60분 정도 기다립니다

    잉크가 내부 패드에 충분히 흡수될 때까지 뚜껑을 닫아 보관해 주세요.

  4. 이면지에 테스트합니다

    처음에는 잉크가 진하게 나올 수 있으니 이면지에 여러 번 테스트 후 사용해 주세요.

충전 후 뚜껑을 닫고 60분 정도 기다린 뒤, 이면지에 여러 번 테스트해 주세요.

60분 정도 기다리기
